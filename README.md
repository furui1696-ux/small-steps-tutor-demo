# Small Steps 家教演示页

英文静态单页，包含课程、服务对象、虚构老师简介、常见问题和预约演示弹窗。纯 HTML / CSS / JavaScript，无需安装依赖。

## 本地预览

直接用浏览器打开 `index.html`，或在这个目录执行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:4173 。

## 演示边界

- 老师 Ellis、Small Steps 品牌和课程安排均为虚构示例，页面明确标注 Demo project。
- 无虚构评价、资质或教学成绩，不售卖课程。
- 预约表单只在当前弹窗内显示预览；不发送网络请求，不使用浏览器持久存储，关闭弹窗即清空。
- 表单建议使用示例信息；未成年人由家长或监护人预约的说明已包含。
- 要用于真实客户，需要替换真实资料，设置真实价格和政策，并接入预约服务。

## 文件

- `index.html`：英文内容及页面结构。
- `styles.css`：响应式样式，支持系统深色模式和减少动态效果设置。
- `app.js`：预约弹窗、表单校验、本地预览。
- `assets/study.jpg`：学习场景照片，来自 Unsplash（photo-1434030216411-0b793f4b4173）。照片仅表示学习场景，不代表示例老师或真实学员。
